	\subsection{Mục đích tài liệu}
	
	Tài liệu này mô tả các yêu cầu phần mềm của hệ thống
	\textbf{LivingDocs -- Design and Implementation of an AI-Assisted
		Self-Updating Document System for Engineering Teams}.
	
	LivingDocs là hệ thống hỗ trợ duy trì tài liệu phần mềm bằng trí tuệ nhân tạo,
	nhằm phát hiện documentation drift, hỗ trợ tạo và cập nhật tài liệu từ mã nguồn,
	đồng thời cung cấp quy trình kiểm duyệt có sự tham gia của con người.
	
	Tài liệu tập trung vào:
	\begin{itemize}
		\item Yêu cầu của người dùng.
		\item Yêu cầu chức năng.
		\item Yêu cầu phi chức năng.
		\item Vai trò và quyền của các nhóm người dùng.
		\item Quy trình quản lý tài liệu và documentation drift.
		\item Các yêu cầu về kiểm duyệt, truy vết và phiên bản tài liệu.
	\end{itemize}
	
	Tài liệu này \textbf{không mô tả chi tiết thiết kế hệ thống,
		kiến trúc triển khai, cấu trúc cơ sở dữ liệu hoặc mã nguồn}.
	Các nội dung này thuộc các giai đoạn thiết kế và triển khai sau của dự án.
	
	% =========================================================
	\section{Phạm vi hệ thống}
	% =========================================================
	
	LivingDocs hướng tới việc tự động hóa quá trình duy trì tài liệu trong
	các dự án phần mềm.
	
	Hệ thống có khả năng:
	
	\begin{itemize}
		\item Kết nối với GitHub repository.
		\item Tiếp nhận thay đổi từ commit và Pull Request.
		\item Phân tích thay đổi mã nguồn.
		\item Liên kết mã nguồn với tài liệu tương ứng.
		\item Phát hiện documentation drift.
		\item Phân loại mức độ và loại drift.
		\item Đề xuất cập nhật tài liệu bằng AI.
		\item Tự động tạo tài liệu từ mã nguồn.
		\item Quản lý phiên bản và lịch sử thay đổi của tài liệu.
		\item Hỗ trợ quy trình kiểm duyệt bởi Staff và Manager.
		\item Cung cấp knowledge base để tìm kiếm và liên kết tài liệu với mã nguồn.
		\item Cung cấp chức năng quản trị và cấu hình hệ thống.
	\end{itemize}
	
	% =========================================================
	\section{Mục tiêu hệ thống}
	% =========================================================
	
	Các mục tiêu chính của LivingDocs gồm:
	
	\begin{itemize}
		\item Giảm documentation debt trong quá trình phát triển phần mềm.
		\item Phát hiện tài liệu không còn đồng bộ với mã nguồn.
		\item Phát hiện cả thay đổi tham chiếu và thay đổi mang tính ngữ nghĩa.
		\item Giảm công sức thủ công trong việc viết và duy trì tài liệu.
		\item Tăng độ chính xác và tính nhất quán của tài liệu.
		\item Hỗ trợ tự động tạo tài liệu từ mã nguồn.
		\item Đảm bảo mọi thay đổi tài liệu đều có thể truy vết.
		\item Đảm bảo AI hoạt động dưới sự kiểm soát của con người.
		\item Hỗ trợ quy trình review và approval trước khi tài liệu được publish.
	\end{itemize}

	% =========================================================
	\section{Yêu cầu người dùng}
	% =========================================================
	
	\subsection{Developer (Author)}
	
	Developer cần có khả năng:
	
	\begin{itemize}
		\item Đăng ký, đăng nhập và đăng xuất.
		\item Quản lý thông tin cá nhân và notification preferences.
		\item Kết nối tài khoản GitHub.
		\item Chọn repository và thêm repository vào workspace.
		\item Xem trạng thái kết nối repository.
		\item Đồng bộ lại repository khi cần.
		\item Xem Pull Request và commit đã được hệ thống tiếp nhận.
		\item Tạo tài liệu từ source code bằng AI.
		\item Chọn template cho tài liệu được tạo.
		\item Xem các code entity chưa có tài liệu.
		\item Xem trước tài liệu do AI tạo.
		\item Chỉnh sửa tài liệu trước khi gửi review.
		\item Xem grounding evidence của tài liệu.
		\item Gửi tài liệu vào workflow review.
		\item Xem trạng thái workflow của tài liệu.
		\item Xem documentation drift alert.
		\item Xem code change và evidence liên quan.
		\item Xem loại và mức độ nghiêm trọng của drift.
		\item Xem và xử lý đề xuất cập nhật tài liệu từ AI.
		\item Xem lịch sử phiên bản tài liệu.
		\item So sánh các phiên bản tài liệu.
		\item Roll back tài liệu về phiên bản trước.
		\item Tìm kiếm tài liệu và code entity trong knowledge base.
	\end{itemize}
	
	\subsection{Staff (Reviewer)}
	
	Staff cần có khả năng:
	
	\begin{itemize}
		\item Xem hàng đợi tài liệu đang chờ review.
		\item Mở tài liệu cùng grounding evidence.
		\item Xem change log trong quá trình review.
		\item So sánh phiên bản được tạo/cập nhật với phiên bản đã được approve.
		\item Kiểm tra tài liệu có tuân theo template hay không.
		\item Kiểm tra nội dung tài liệu có phù hợp với source code hay không.
		\item Thêm review comment.
		\item Yêu cầu chỉnh sửa tài liệu.
		\item Chỉnh sửa các lỗi nhỏ trong tài liệu.
		\item Approve tài liệu ở bước Staff review.
		\item Reject tài liệu và gửi feedback cho Developer.
		\item Lọc và sắp xếp review queue.
		\item Xem review history và trạng thái tài liệu.
	\end{itemize}
	
	\subsection{Manager (Approver)}
	
	Manager cần có khả năng:
	
	\begin{itemize}
		\item Xem tài liệu đã vượt qua Staff review.
		\item Xem Staff review comments.
		\item Xem grounding evidence.
		\item Xem toàn bộ audit trail của tài liệu.
		\item Approve tài liệu để publish hoặc commit.
		\item Reject tài liệu hoặc yêu cầu chỉnh sửa.
		\item Roll back tài liệu về phiên bản đã được approve trước đó.
		\item Cấu hình loại tài liệu yêu cầu Manager approval.
		\item Cấu hình merge policy cho documentation drift nghiêm trọng.
		\item Đảm bảo tài liệu chỉ được publish hoặc commit sau khi được phê duyệt.
		\item Xem lịch sử các quyết định approval.
		\item Delegate hoặc reassign trách nhiệm approval.
	\end{itemize}
	
	\subsection{Technical Lead / Documentation Owner}
	
	Technical Lead / Documentation Owner cần có khả năng:
	
	\begin{itemize}
		\item Quản lý documentation collections.
		\item Gán quyền sở hữu tài liệu.
		\item Cấu hình documentation drift policy.
		\item Cấu hình drift thresholds.
		\item Theo dõi documentation health dashboard.
		\item Xem documentation-to-code dependency graph.
		\item Xem các chỉ số chất lượng tài liệu.
		\item Theo dõi các documentation drift chưa được xử lý.
		\item Xuất documentation health và compliance reports.
		\item Cấu hình automatic documentation update policy.
		\item Theo dõi version history và change log.
		\item Lọc change log theo role, document, repository hoặc thời gian.
		\item Roll back tài liệu hoặc documentation collection.
		\item Tạo, chỉnh sửa, clone và xóa documentation template.
		\item Quản lý template sections, headings và placeholders.
		\item Quản lý thư viện template mặc định.
		\item Gán default template cho documentation collection hoặc document type.
		\item Quản lý version của template.
		\item Preview template trước khi publish.
	\end{itemize}
	
	\subsection{Administrator}
	
	Administrator cần có khả năng:
	
	\begin{itemize}
		\item Quản lý users, roles và permissions.
		\item Quản lý Developer, Staff, Manager, Technical Lead và Administrator.
		\item Quản lý Staff và Manager trong approval workflow.
		\item Quản lý workspace và repository.
		\item Cấu hình GitHub App và GitHub OAuth.
		\item Cấu hình GitHub Actions và webhook integration.
		\item Quản lý external service integrations.
		\item Cấu hình source-code languages được hệ thống hỗ trợ.
		\item Cấu hình documentation generation settings.
		\item Cấu hình automatic documentation update trigger.
		\item Cấu hình auto-update policy.
		\item Cấu hình change-log và audit-log retention.
		\item Cấu hình AI settings.
		\item Cấu hình documentation indexing và retrieval.
		\item Theo dõi AI processing jobs.
		\item Theo dõi event pipelines và system health.
		\item Xem audit logs và system analytics.
		\item Cấu hình notification policies.
	\end{itemize}

	rollback và kiểm tra nguồn gốc của documentation.
