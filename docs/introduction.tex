\section{Introduction}
\subsection{Project Overview}
Trong quá trình phát triển phần mềm hiện đại, tài liệu kỹ thuật đóng vai trò quan trọng giúp nhóm phát triển, kiểm thử và bảo trì hệ thống một cách hiệu quả. Tuy nhiên, ở nhiều dự án thực tế, tài liệu thường không được cập nhật kịp thời khi mã nguồn thay đổi, dẫn đến sự không đồng bộ giữa tài liệu và hệ thống đang triển khai.
Để giải quyết vấn đề này, nhóm đề xuất xây dựng hệ thống \textbf{LivingDocs} – một nền tảng hỗ trợ quản lý tài liệu phần mềm thông minh, có khả năng kết nối trực tiếp với GitHub để theo dõi sự thay đổi của mã nguồn và tự động đề xuất cập nhật tài liệu bằng công nghệ Trí tuệ nhân tạo (AI).
LivingDocs giúp giảm khối lượng công việc thủ công trong quá trình viết tài liệu, đồng thời nâng cao tính chính xác, khả năng truy vết và tính nhất quán giữa mã nguồn và tài liệu kỹ thuật.
\subsection{Objectives}
Mục tiêu của hệ thống bao gồm:
\begin{itemize}
    \item Tự động phát hiện thay đổi của mã nguồn trên GitHub.
    \item Sinh tài liệu kỹ thuật bằng AI.
    \item Phát hiện sự sai lệch giữa mã nguồn và tài liệu.
    \item Hỗ trợ cộng tác nhiều thành viên trong cùng một dự án.
    \item Quản lý phiên bản tài liệu và lịch sử thay đổi.
\end{itemize}
\subsection{Project Scope}
Hệ thống LivingDocs tập trung vào việc hỗ trợ các nhóm phát triển phần mềm trong quá trình xây dựng và bảo trì tài liệu kỹ thuật.
Các chức năng chính gồm:
\begin{itemize}
    \item GitHub Integration.
    \item AI Documentation Generation.
    \item Automatic Documentation Update.
    \item Documentation Drift Detection.
    \item Knowledge Base Management.
    \item Workflow Collaboration.
    \item System Administration.
    \item Testing and Deployment.
\end{itemize}
